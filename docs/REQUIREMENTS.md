# Requirement traceability

Current public release by **BanuSreya**: https://sahaaya-mauve.vercel.app. The original master brief is broader than the hackathon demonstration; this table distinguishes working behavior from unverified or inactive integrations.

| Brief area                | Delivered                                                                                                                                                                      | Remaining or constrained                                                                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Brand and landing         | Original heart/hands logo, family illustration, responsive landing, BanuSreya attribution, source link and social preview                                                      | No claim of design/usability research                                                                                                                        |
| Six languages             | UI catalog, saved preference, locale dates and privacy/account-rights page in English, Telugu, Tamil, Hindi, Kannada, Malayalam                                                | Native-speaker/clinical review; source medical text is preserved                                                                                             |
| Authentication            | Passwords, MFA/TOTP/recovery codes, QR enrollment, PIN, session revocation, consented onboarding, export/deletion with fresh identity proof                                    | Email ownership/recovery adapters inactive without a sender; mobile ownership verification absent                                                            |
| Roles and consent         | Per-request permissions, single-use email-bound invitations/QR, revocation, verified-doctor checks and operator-gated verification form                                        | A real operator and live verified clinician onboarding remain unconfigured                                                                                   |
| Scan-to-Care              | Real browser image/PDF OCR, five-page cap, quality warnings, raw barcode, provenance, editable review, document history; fictional medicine sample → reviewed draft → approval | Clinical handwriting accuracy and medicine authenticity lookup unverified; local transcript does not automatically create medicine/vital/appointment records |
| SmartDose                 | Daily/weekdays/alternate/finite/PRN schedules, atomic confirmations, caregiver witness, snooze/help, stock/refills and expiry                                                  | Pharmacy fulfillment absent; regimen changes use a new reviewed draft                                                                                        |
| Care Loop                 | Independent scheduler, staged alerts, human acknowledgement/resolution, quiet hours, retry/claims, receipt separation; personal-account push self-test                         | Ten-minute free-host cadence; real-device/inbox acceptance tests and production load/chaos tests outstanding                                                 |
| Companion                 | Authorized record lookup, source-backed responses, reviewed journal/appointment drafts and browser voice fallback                                                              | Cloud generative AI is off for private data; no diagnosis or automatic writes                                                                                |
| Family and handover       | Patient-controlled members, tasks/reassignment, notes, structured shared-permission snapshots and recipient acknowledgement                                                    | Downloaded/shared copies cannot be recalled                                                                                                                  |
| DoctorConnect             | Requests, manual clinic reference confirmation, reschedule/cancel/complete, private iCalendar export, professional application/hours fields, patient-approved summary          | Calendar import is explicit, not automatic sync; no automatic clinic booking or verified external clinician directory                                        |
| Health intelligence       | Custom date ranges, heatmap/status table, recorded vital trends, refill history, adherence distinction                                                                         | No diagnostic score; bounded requests reject oversized ranges                                                                                                |
| Emergency Passport        | Minimal profile, QR, expiring/revocable link, printable view; keyless Google Maps hospital-search link                                                                         | Maps handles optional location permission; no offline PHI cache or emergency-response guarantee                                                              |
| Records and privacy       | Authenticated private files, encrypted production storage, search/pagination, versioned metadata, reviewed extraction, export/deletion and cleanup queue                       | Malware scanning, provider retention policy and restore drill still required                                                                                 |
| Google/email integrations | Keyless Maps links and calendar-file export; typed optional Google, Resend and Brevo adapters; signed/deduplicated Resend webhook code                                         | Google APIs and both email providers inactive on public deployment; Brevo sender activation and inbox verification still required                            |
| Accessibility             | Labelled controls, keyboard dialogs, reduced motion, Easy Mode, mobile layout and axe checks                                                                                   | Screen-reader/elderly user studies and formal audit outstanding                                                                                              |
| Demo                      | Four selectable roles, fictional shared data, sample review workflow, labelled reset/simulation                                                                                | Do not enter real patient data; shared demo actions can affect other demo viewers                                                                            |
| Deployment                | Vercel + Neon + Cloudflare; database/worker health and synthetic production persistence/privacy smoke checked                                                                  | Free quotas/sleep; no clinical SLA                                                                                                                           |
| Repository/submission     | Public BANU-09 source, BanuSreya author, CI, lockfile/migrations, license, judge walkthrough and evidence                                                                      | LinkedIn publication and organizer tag handled by entrant                                                                                                    |
