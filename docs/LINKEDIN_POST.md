Who follows up when an older adult's medicine reminder goes unanswered?

I built SAHAAYA to help older adults and their families coordinate the everyday work of care: medicines, appointments, records and follow-up—with the patient controlling who can access what.

The core workflow is simple:
Read a document → review it → approve a medication schedule → confirm or request help → let the care circle follow up.

Working features include:
• Six languages and an elderly-first, responsive interface with Easy Mode.
• Private, on-device OCR for images and PDFs, with original-document comparison and field-by-field review.
• Medication schedules, refill tracking, caregiver handovers and shared appointments.
• Patient-controlled permissions, authenticator MFA, private documents, data export and account deletion.
• Adherence heatmaps, recorded vital trends and a companion grounded in authorized saved records.

This is a full-stack application using Next.js, TypeScript, PostgreSQL and a separate scheduled worker. Local validation passed 99 unit tests and 34 browser/API journeys, including mobile, accessibility, security and cross-role workflows.

Try the fictional demo: https://sahaaya-mauve.vercel.app/demo
Explore the code: https://github.com/BANU-09/sahaaya

The public deployment uses free hosting. It is a hackathon demonstration, not a medical or emergency service. Human review is required; an unanswered reminder is never automatically treated as a missed dose. Cloud AI, email/SMS and live clinic booking are not enabled.

Thank you to Makers Need More (MnM) for the opportunity to build and demonstrate this project.
